## 3. 阻塞项

### P0-1：Supabase 缺少 `competitions.summary`

真实请求失败：

```text
column competitions.summary does not exist
```

API 已查询该字段，迁移文件也已定义该字段，说明连接的数据库没有执行最新迁移。

影响：竞赛库、推荐候选读取、收藏详情及相关管理页面。

处理：在目标 Supabase SQL Editor 依次执行 `migration.sql` 和 `migration_auth.sql`，再验证 `/api/competitions` 返回 200。

### P0-2：Render CORS 仍为示例域名

`render.yaml` 当前设置 `https://saizhitong.example.com`，与 GitHub Pages 生产前端不一致。

影响：浏览器可能拦截前端对后端的全部跨域请求。

处理：改为真实 GitHub Pages Origin 或实际自定义域名。

### P0-3：全量测试未通过

正式验收不应在已知回归测试失败的情况下进行。失败包括实际流程缺口、日期解析错误、刷新统计错误和文案规范不一致。

## 4. 主要回归

### 对话和材料流程

- 用户发起材料任务后只补充专业和年级，下一步问题可能返回 `None`；
- 从多个推荐中选择竞赛后，材料类型提示与约定流程不一致；
- 缺少候选数据、Supabase RLS 失败及“什么信息”追问的解释与既定规范不一致。

### 数据采集

- 52竞赛网“截止时间”没有被列表解析器识别；
- DataFountain 列表中的 `race` 时间没有写入比赛时间；
- DataFountain ISO 时间转北京时间后出现日期跨天，与测试约定的官网日期口径不一致。

### 刷新任务

刷新服务只统计 `items_updated`，对返回 `items_changed` 的实现或测试替身不兼容，变化数可能错误显示为 0。

### 测试工程

仓库根目录 `test_crawler.py` 是带参数的手工诊断脚本，但因文件名被 pytest 自动收集，产生 3 个 fixture 错误。应改名或通过 `pytest.ini` 限定 `testpaths = tests`。

## 6. 环境注意事项

本地 Python 环境最初缺少 `python-jose`。补装后，共享 Anaconda 环境出现 `pyasn1` 与旧版 `pyasn1-modules` 的依赖冲突。项目验收应使用 Python 3.11 独立虚拟环境或容器。

一次 `compileall` 检查受到已有 `__pycache__` 文件权限影响，该现象属于本地环境问题；实际模块加载、专项测试及 FastAPI 启动均成功。
